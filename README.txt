E-COMMERCE SALES DATA CLEANING PROJECT

Project type: Portfolio demonstration

Objective:
Clean and organize a sample e-commerce sales dataset and document the data-quality issues found.

Work completed:
- Removed 1 duplicate record.
- Identified 1 missing quantity value and flagged it for review.
- Standardized text formatting.
- Created a cleaning log and data-quality summary.
- Preserved the original raw data separately from the cleaned data.

Files:
- Excel workbook: Raw data, cleaned data, summary, and cleaning log.
- Case study: Project explanation and screenshots.

Note:
This is a self-directed portfolio project using sample data. It is not client work.
